# 환경 사실 (운영자가 관리, 에이전트는 읽기만 한다. 2026-10-25 작성)

- 센서는 공유기 NAT 바깥(ISP 구간)에 인라인으로 있다. 집 전체가 공인 IP 하나로 보여 내부 호스트를 구분할 수 없다. 대부분의 alert에서 반복되는 목적지 IP가 집이다.
- 집 공인 IP는 ISP 사정으로 바뀔 수 있다. 특정 주소를 고정 식별자로 판단 근거 삼지 않는다.
- 센서는 인바운드와 아웃바운드를 모두 본다.
- 공유기 포트포워딩은 0개다(운영자 확인). 외부에서 집으로 들어오는 연결을 받도록 설정한 서비스가 없다. 그래서 "포트 노출 여부 확인"은 권고하지 않는다.
- 192.0.2.1(RFC 5737 문서용 주소)로 가는 alert는 운영자의 룰 검증용 테스트다.
- testmyids.com 접속과 운영자의 nc 테스트는 검증 트래픽이다. 근거 없이 침해로 판단하지 않는다.
- Tailscale 피어 간 통신(UDP 41641, DERP 릴레이)은 SOC 자신의 인프라 경로다.
- 분석 서버(EC2)에는 운영자가 붙인 IAM 역할이 없다. aws:ec2-instance, aws:ec2-infrastructure 세션은 AWS가 관리하는 것이다.
- AWS 계정 정상 활동 주체(2026-10-11~25 CloudTrail 실측): 운영자 IAM 사용자 1명, 로그 수집 전용 IAM 사용자 1명(S3 읽기만), AWS 서비스 역할(resource-explorer 등). 이 밖의 IAM 사용자, 새 액세스 키, 처음 보는 역할은 이상으로 본다.
- 루트 계정은 이 기간 사용 0건이다. 루트 활동은 그 자체로 이상이다.
- 로그 수집 전용 사용자가 S3 읽기 외의 API(IAM, EC2, CloudTrail 설정 변경 등)를 호출하면 자격증명 유출을 의심한다.
