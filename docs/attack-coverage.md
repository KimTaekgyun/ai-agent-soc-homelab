## 보이지 않는 것 (구조적 공백)

| 영역 | 이유 |
|---|---|
| 실행·지속성·권한 상승 (TA0002/0003/0004) | 호스트 로그(EDR, Sysmon 등) 없음. 네트워크·클라우드 API만 봄 |
| 내부 이동 (TA0008) | **센서 위치 선택의 대가.** 회선 전체를 한 지점에서 보려고 공유기 바깥에 둠 → 기기 간 통신은 공유기 내부 스위치에서 끝나 센서를 지나지 않음. 보완: 공유기 안쪽에 포트 미러링 스위치를 두고 복사본을 센서로, 또는 호스트 로그(Sysmon·EDR) |
| 자격 증명 접근 (TA0006) | 인증 로그 수집 없음. SSH·RDP 스캔은 보이지만 무차별 대입 성공 여부는 모름 |
| 암호화된 통신의 내용 | TLS는 핸드셰이크(SNI·인증서)까지만 보임 |
| 클라우드의 나머지 기법 | IAM 변경(T1098), 루트 계정 사용(T1078.004), 비정상 리전 리소스 생성 등은 설계만 있고 미구현 |
